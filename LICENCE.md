## 🧩 About

**Path of Exile 2 Companion** is a curated list of Path of Exile 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap markers, health bars
- **Quality-of-Life Helpers** — loot filter manager, inventory sorter, overlay notes
- **Research Notes** — boss patterns and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🗺️ Mapping & Navigation
- Minimap Markers — highlight important locations and points of interest
- Health Bars — display enemy and ally health for study
- Overlay Map — full-screen map overlay for planning routes
- Waypoint Notes — save and review navigation paths

### 🧰 Inventory & Loot
- Loot Filter Manager — organize and apply custom loot filters
- Inventory Sorter — one-click sorting for stash and inventory
- Item Highlight — mark valuable items for single-player review
- Stash Search — quick search across tabs

### 🏋️ Practice & Build
- DPS Meter — track damage output for build testing
- Cooldown Tracker — monitor skill cooldowns
- Build Planner — theorycraft and compare passive trees
- Trade Helper — price check notes for single-player economy study
